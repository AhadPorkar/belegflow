# Contributing

Work on a branch. Describe the business invariant and add its failing regression test first. Use decimal strings/BigDecimal for money, server-derived tenant identity and explicit workflow commands. Never bypass invoice versions or audit writes. Add Flyway migrations instead of editing deployed ones. Keep EN/DE keys and interpolation placeholders identical. Do not store API tokens in browser localStorage.

Run domain, server adapter, real PostgreSQL integration, frontend and browser tests. A successful dependency-free test is not permission to claim a full-stack build. Update the API reference, code map and guides when behavior changes. Keep screenshots synthetic. The compatibility showcase is a separate demonstration, not a production dependency.

The initial source was AI-assisted and requires maintainer review. Do not claim unsupported performance metrics, production customers, compliance certification or integration status in a pull request or portfolio page. Review the proposed MIT license and third-party obligations before publication.
